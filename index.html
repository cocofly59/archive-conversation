Install archive-conversation

A Claude plugin that saves a conversation and every file it produced into one archive you can download. Works on a phone, on the web, and on a computer.

  1. Copy the marketplace name:
    cocofly59/archive-conversation
  2. Open your Claude plugins page and sign in if asked: Open Claude plugins
  3. Tap Add, then Add marketplace, paste the name, and confirm.
  4. Open archive-conversation in the list and tap Add.
  5. Start a new conversation or Cowork task in the Claude app and say "Archive this conversation".

On a phone, menus missing?

In Safari, tap aA in the address bar, then Request Desktop Website. In Chrome, open the menu and tick Desktop site. The plugin is saved to your Claude account, so adding it once is enough for all your devices.

Other ways

Upload a file: download the plugin, then on the plugins page choose Add > Upload plugin.

Download the plugin file

Claude Code:

/plugin marketplace add cocofly59/archive-conversation
/plugin install archive-conversation@archive-conversation
